# CodeBuddy-Website-Copy

专为开发者工具、SaaS 和 AI 产品服务的顶尖文案与网页设计专家 Skill。

## 📋 简介

此技能（Skill）将复杂的技术功能转化为专业、清晰且极具说服力的网站内容。当你需要为科技产品创建官网首页、产品落地页文案，或模仿腾讯云 CodeBuddy 等现代科技产品官网风格时，使用此技能。

## ✨ 核心特性

- **专业信赖的调性**：采用经验丰富的技术专家语气，冷静、自信、不浮夸
- **开发者中心视角**：从开发者的真实痛点、工作流和效率提升出发
- **智能高效表达**：突出 AI 的"开箱即用"、"一键生成"、"精准推荐"
- **现代科技感**：用词精炼、前沿，体现技术深度

## 🎯 目标受众

此技能支持分层沟通，覆盖四类用户：

1. **技术决策者/Leader** - 关心团队协作、代码规范沉淀、全链路打通
2. **资深开发者** - 关心代码质量、新语法学习门槛、复杂业务逻辑
3. **初/中级开发者** - 关心降低入门门槛、理解代码结构、快速掌握新语言
4. **非纯开发角色** - 关心"设计到代码"的一键转换、无需编码即可实现想法

## 📐 文案写作公式

### 标题公式
```
[量化结果] + [核心操作] + [价值描述]
```
示例："0 门槛新建项目，开箱即用的流程体验"

### 描述公式
```
用户角色（可选）+ 功能：+ 具体操作 + 带来的直接好处
```

### 证言公式
```
"直接引语，包含具体功能点"（用户名，X年经验，职位）
```

### FAQ 公式
直接使用技术问题作为标题，下方给出明确、步骤化的解决方案

## 📄 输出结构

使用此技能会生成包含以下 7 个部分的完整网站内容：

1. **主页首屏** - 产品名称、核心价值主张、主要操作按钮
2. **场景一** - 标题、描述、功能亮点列表
3. **场景二** - 标题、描述、功能亮点列表
4. **用户证言** - 至少 3 条用户证言（含用户身份）
5. **技术生态/集成亮点** - 支持的技术栈、平台、集成能力（可选）
6. **常见问题（FAQ）** - 至少 3 个技术问题及解答
7. **底部行动号召（CTA）** - 强化性语句 + 醒目的 CTA 按钮

## 🚀 使用方法

### 在 CodeBuddy 中使用

直接在 CodeBuddy 对话中输入以下触发语句：

```
使用 CodeBuddy-Website-Copy skill，为我的 [产品名称] 创建官网首页文案
```

### 触发关键词

此技能会在以下场景自动触发：

- "帮我设计一个开发者工具的产品官网"
- "为我的 AI 编程助手写网站文案"
- "生成一个 SaaS 产品的落地页内容"
- "模仿腾讯云 CodeBuddy 的官网风格写文案"
- "为我的技术产品创建首页内容"

## 📥 安装方法

### 方法 1：从 GitHub 仓库安装

```bash
git clone https://github.com/shanriver2018/CodeBuddy-Website-Copy.git ~/.codebuddy/skills/CodeBuddy-Website-Copy
```

### 方法 2：手动安装

1. 下载此仓库的 ZIP 文件
2. 解压到 `~/.codebuddy/skills/CodeBuddy-Website-Copy/` 目录
3. 重启 CodeBuddy

## 📝 使用示例

### 输入信息

当使用此技能时，你需要提供以下信息（如缺失，技能会引导你提供）：

1. **产品名称**：例如 "DevAssist AI"
2. **一句话产品定位**：例如 "AI 驱动的智能代码审查助手"
3. **3-5 个核心功能点**：例如 "智能代码审查、自动生成测试用例、代码质量评分"
4. **主要目标用户**：从四类受众中选择
5. **2-3 个具体使用场景**：例如 "代码审查流程优化、新成员代码规范培训"

### 输出示例

技能会生成类似以下结构的完整内容（实际输出会根据输入定制）：

```markdown
# DevAssist AI - AI 驱动的智能代码审查助手

## 0 门槛接入现有工作流，3 倍提升代码审查效率

[场景一、场景二、用户证言、技术生态、FAQ、CTA 等完整内容...]
```
