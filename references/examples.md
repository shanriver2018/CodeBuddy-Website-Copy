## FAQ 示例（遵循：技术问题标题 + 步骤化解决方案）

### 如何在现有项目中集成 CodeBuddy？

1. 安装 VS Code 或 JetBrains 插件
2. 打开项目文件夹，CodeBuddy 自动分析项目结构
3. 根据提示配置团队编码规范（可选）
4. 开始编码，CodeBuddy 会自动提供智能建议

### CodeBuddy 是否支持私有部署？

支持。企业版提供完整的私有部署方案，包括：
- 本地服务器部署
- 与内部 Git 仓库集成
- 自定义 AI 模型训练
- 完整的权限管理和审计日志

### 如何处理代码隐私和安全问题？

CodeBuddy 提供多重安全保障：
1. 所有代码分析在本地完成，不会上传到云端
2. 支持完全离线模式，使用本地 AI 模型
3. 企业版支持私有云部署，数据完全隔离
4. 通过 SOC 2 Type II 安全认证
